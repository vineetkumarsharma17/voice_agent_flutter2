Model assets live under this folder. Download the ONNX model files and voice data listed in
`docs/MODEL_DOWNLOADS.md`, then place them into the matching directories.

This repository does not bundle model binaries to keep size reasonable.

Intent classification models (TFLite) also live under `assets/models/intent/`.
Slot tagging models live under `assets/models/slots/`.
Response selection models live under `assets/models/response/`.
